# AI 创意应用 - 大肥鱼清除计划浏览器插件项目

> 用 AI 编程半天做出 B 站「大肥鱼」评论清理插件，附开源项目实现原理拆解



本项目是一个有趣的 AI 创意应用，利用 AI 编程在半天时间内开发出一款 Chrome / Edge 浏览器插件，能够自动识别并本地隐藏 B 站评论区和 UP 主空间主页里的 AI 自动运营账号（网友戏称的「蓝色大肥鱼」），支持本地规则识别、可选 DeepSeek 大模型精判以及多种趣味赶鱼动画。

本文不涉及繁琐的手写代码过程，主要带你了解这个创意插件的诞生背景、核心功能与底层实现原理，帮你开拓 Vibe Coding 的创意实践思路。

项目代码免费开源：https://github.com/liyupi/dafeiyu-cleaner

视频版演示：https://bilibili.com/video/BV1Ywn46EEyF

## 这个插件是怎么实现的？

看到这里，你可能会好奇，这个半天做出来的浏览器插件，底层到底是怎么识别出大肥鱼，又是怎么把它们赶走的呢？

我结合开源仓库里的源码给大家拆解一下。

其实整个插件并没有依赖任何前端打包框架，而是直接用纯原生 JavaScript 写成的一个 Chrome MV3 扩展，同时也兼容 Firefox 浏览器。整套代码的运行思路非常清晰，顺着获取数据、识别账号、执行动画这三个环节就能全部看懂。

想要识别大肥鱼，插件第一步得先拿到评论区里每条评论的作者信息和发言内容。B 站新版评论区采用了自定义网页组件和 Shadow DOM 来渲染，每条评论的完整原始数据都直接挂载在页面元素的 `.data` 属性上。不过浏览器扩展的普通脚本默认运行在隔离环境里面，直接访问是读取不到这个属性的。为了解决这个问题，项目把脚本拆成了两组来互相配合。系统先通过 `main-world.js` 注入到网页的主环境中，主动监听评论组件的挂载和更新事件，再配合每 1.5 秒一次的定时扫描作为兜底。每当页面加载出新的评论，这个脚本就会把评论者的昵称、签名、等级、头像地址、正文内容以及艾特对象全部提取出来，再通过 `window.postMessage` 发送给隔离环境里的 `comments.js` 进行处理。与此同时，插件自己的悬浮鲸鱼娘、对话气泡和操作按钮全部渲染在一个独立的 Shadow DOM 容器里面，这样插件的界面样式就不会和 B 站原本的页面样式互相冲突。

拿到评论数据之后，插件接下来就要判断每个账号到底像不像大肥鱼，这里采用的是「本地规则初筛加上可选大模型精判」的两层设计。第一层是运行在本地的离线识别引擎 `detector.js`，它会把同一个账号在当前页面发过的所有评论合并到一起，再从多个维度依次计算分数。引擎首先会查看账号的基础资料，如果昵称里包含 DeepSeek、大肥鱼、鲸鱼娘、白饭这类关键词，签名里写着主人家养或者 AI 代运营，或者是刚注册不久的 Lv2 小号，引擎就会给这个账号加上对应的嫌疑分。更有意思的是，代码还会把账号的头像缩小成 32 × 32 像素的小图绘制到画布里面，逐个像素统计其中的「鲸鱼蓝」占比，只要蓝色像素的比例达到 40% 以上，这个账号就会立刻被加上 22 分。反过来，如果这个账号是 Lv6 老用户、拥有官方认证、开通了大会员，或者是当前视频的 UP 主本人，引擎就会主动给它减分，尽量避免误伤真人观众。

除了检查账号资料，离线引擎还会仔细分析评论正文和页面上下文。如果一条评论里面出现了「本鲸」「住在 DSH 里」这类自曝身份的表达，或者在括号里扮演摇尾巴、吐泡泡的动作，又或者像读过字幕一样罗列视频要点、残留着 Markdown 排版符号，甚至在开头艾特了一个和自己昵称很像的「主人」，引擎都会给它累加较高的分数。此外，如果同一个账号在当前页面连续刷了多条评论，或者在楼中楼里被其他真人点名指出是大肥鱼，又或者它之前在别的视频页面就已经被插件认出过，这些异常行为和跨页面前科都会继续推高它的得分。反之，如果评论内容是在认真提问求助，或者带着非常自然的真人玩梗吐槽，引擎就会适当扣减它的嫌疑分。所有维度都计算完成之后，离线引擎会给出一个 0 到 99 之间的综合概率分，一旦达到设定的阈值，页面就会把这个账号标记为大肥鱼。

当然，单靠本地规则难免会遇到一些真假难辨的灰色账号，这时候就轮到第二层的 DeepSeek 大模型精判登场了。只要你在插件设置里填好了自己的 DeepSeek API Key，后台服务脚本 `background.js` 就会专门挑出离线得分落在 20 到 85 分之间、规则引擎拿不准的账号，每批最多打包 8 个，把它们的评论内容、离线得分和命中原因一起发送给 DeepSeek 接口。大模型会按照提示词的要求，以鲸鱼娘的口吻给出每个账号的 AI 概率以及一句简短的吐槽。收到大模型的返回结果之后，插件会把离线分数按 45% 的权重、大模型分数按 55% 的权重加权合并成最终结果。而在打开 UP 主空间主页进行鉴定时，大模型的权重还会进一步提高到 70%，并且使用 `deepseek-flash` 模型时还会顺便查看对方的头像图片。为了帮你节省 API 费用，精判过的结果会在本地缓存 7 天，不会反复请求。而且你的 API Key 只保存在本机的浏览器存储空间里，所有精判请求也只发往 DeepSeek 官方接口，不会经过任何第三方中转服务器。

识别完成后，最后一步就是大家看到的趣味赶鱼动画和本地隐藏效果了。当你点击「回家吃白饭」或者触发「响指清场」时，项目里的角色模块 `actors.js`、武器模块 `weapons.js` 和特效模块 `fx.js` 会开始联动。悬浮在页面上的鲸鱼娘会先移动到目标头像的右侧，接着页面会在头像旁边生成一只迷你大肥鱼小人，依次切换被抓包、嘴硬和抱碗逃跑等透明 WebP 动作图片。与此同时，特效模块会用浏览器自带的 WebAudio 实时合成音效，用画布渲染飞溅的粒子，并随机拿出白饭加特林、扫帚或者臭袜子发动攻击。等到武器打出决定性一击的瞬间，评论脚本才会把这条评论节点在本地折叠隐藏，同时把这个账号记录到本地的遣返名单里面，等你下次在别的视频评论区再次遇到它时，插件就会自动帮你处理。整个清理过程完全运行在你自己的浏览器本地，插件既不会读取你的 B 站 Cookie，也不会调用 B 站的任何删除、拉黑或举报接口，所以大家可以放心地安装体验。
