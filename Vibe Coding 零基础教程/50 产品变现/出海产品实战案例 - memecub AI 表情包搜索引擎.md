## 为什么要做这个？

看到这儿你可能会想：这年头，好像也没多少人在网上找表情包了吧？

其实，这个需求就来源于我自己！

我一直觉得，**自己都不用的项目，是没必要硬做的**。

经常看我文章的同学应该知道，我写文章时很喜欢配表情包，能让枯燥的技术内容变得更有趣。以前都是我自己一张张人工去找、再手动放进文章里，费时费力。

![](https://pic.yupi.icu/yuyi/20zv3rkr49bw.jpg)

现在有了 AI，理论上可以直接让 AI 联网搜索表情包、给文章配图。

但实际用下来，问题很多：

- **搜不到想要的图**：试了一圈搜索工具，搜出来的图要么不是表情包，要么糊得没法用，要么根本不是我想要的情绪
- **AI 配得不到位**：AI 经常在不该笑的地方插图，或者选的表情包和上下文对不上，还得我自己返工

所以我需要两样东西：一个 **靠谱的表情包图库**，再加一个 **能给文章自动配图的 Agent**。

既然市面上没有顺手的，那就自己做一个吧！



## 一、表情包图库

首先是表情包图库，这是 memecub 的基础。

我们收录了熊猫头、奶龙、蘑菇头、金馆长、吗喽、哈基米、卡皮巴拉等各种热门表情包，网站浏览和搜索 **永久免费**，打开就能用。

![](https://pic.yupi.icu/yuyi/07-%E8%A1%A8%E6%83%85%E5%8C%85%E5%A4%A7%E5%85%A8.png)

我比较推荐的是 **按情绪搜索**。比如你想表达震惊的情绪，直接搜「震惊」，出来的就是各种震惊反应图，而不是字面相近但实际乱七八糟的图片：

![](https://pic.yupi.icu/yuyi/image-20261027142334512.png)

当然也支持按表情包的角色搜索，比如最近很火的 DeepSeek 鲸鱼娘，一搜一大把：

![](https://pic.yupi.icu/yuyi/04-%E6%90%9C%E7%B4%A2%E9%B2%B8%E9%B1%BC%E5%A8%98.png)

点开任意一张表情包，可以直接下载原图、复制图片，甚至 **一键复制 Markdown** 贴进文章里，写公众号和博客的同学应该懂这有多方便～

而且每张图都有 AI 生成的画面描述，方便 AI 理解图片内容、在合适的位置使用：

![](https://pic.yupi.icu/yuyi/05-%E8%A1%A8%E6%83%85%E5%8C%85%E8%AF%A6%E6%83%85.png)

我还标明了每张图的 **来源和授权信息**，能不能商用一目了然。

如果搜不到想要的表情包也不用担心，搜索结果较少时，memecub 会自动去各大表情包站补充，一分钟后再搜通常就有了。

## 三、AI 自动配图

图库只是第一步，memecub 真正的核心能力是 **AI 自动配图**。

用法超级简单，注册登录后打开「AI 配图」页面，把文章粘贴进去，选一下想配几张图，点击「开始配图」就行。如果是商业稿，还可以勾选「只用可商用的图」。

我直接拿这篇文章开头 “为什么要做这个” 那段来测试一下：

![](https://pic.yupi.icu/yuyi/13-AI%E9%85%8D%E5%9B%BE%E8%BE%93%E5%85%A5.png)

几秒钟后，AI 就读完了全文，自动挑出了 3 个最适合放表情包的句子，并且 **给出了每张图的配图理由**，想要表达的情绪和放的位置都还挺贴切的：

![](https://pic.yupi.icu/yuyi/image-20261027165741507.png)

下方还会直接给出配好图的完整文章，点击「复制 Markdown」，粘贴到编辑器里就能发，比我以前一张张找图快太多了！

![](https://pic.yupi.icu/yuyi/image-20261027143323056.png)



## 四、给 AI 用的表情包工具

前面说了，memecub 不仅是给人用的，**更多是给 AI 用的**。

我给它做了 Agent Skill、MCP、CLI 命令行和 REST API 多种接入方式，几乎覆盖了所有主流 AI 工具。

### 1）Agent Skill

如果你用的是 Claude Code、Codex 或者 Cursor，最推荐装 Skill，不用写代码、不用装任何依赖，复制两行命令就搞定：

```bash
mkdir -p ~/.claude/skills/memecub
curl -o ~/.claude/skills/memecub/SKILL.md https://memecub.com/skill.md
```

![](https://pic.yupi.icu/yuyi/08-Agent%E6%8E%A5%E5%85%A5%E9%A1%B5.png)

装好之后，你只需要对 AI 说一句「给这篇文章配 3 张表情包」，它就会自己读文章、挑位置、搜表情包、放进去。

你还可以这样玩：

- 「给 ./文章.md 配 4 张表情包，直接改文件」
- 「来 5 张熊猫头的表情包让我挑」
- 「第二张不够好笑，换一张」
- 「这篇是给客户写的商业稿，配图只用可商用的」



### 2）MCP 服务

如果你用的是 Claude Desktop、ChatGPT 这类不支持 Skill 的客户端，可以接入 memecub 的远程 MCP 服务，效果一样：

![](https://pic.yupi.icu/yuyi/09-MCP%E6%8E%A5%E5%85%A5.png)



### 3）CLI 和 REST API

开发者也可以用命令行工具，或者直接调用 REST API，把表情包能力接进自己的产品里：

```bash
npx memecub search "无语" --kind meme
memecub match ./article.md --count 4 > article.with-memes.md
```

每条结果都带图片地址、尺寸、授权信息和现成的 Markdown，对 AI 非常友好。另外，配文含脏话的表情包默认不会出现在 Agent 的结果里，用起来更放心。
