你好，我是鱼皮。

我们已经了解了 AI 编程工具的 3 大类型。但无论你选择零代码平台、代码编辑器还是命令行工具，它们背后都有一个共同的核心 —— **AI 模型**。

你可能会好奇：

- Cursor 里可以选 Claude、ChatGPT、Gemini，它们到底有什么区别？
- 为什么有的人说 Claude 编程最强，有的人却更推荐 ChatGPT？
- 国产大模型靠谱吗？和国外的模型差距有多大？

别担心，这篇文章我会用最接地气的方式，带你搞懂主流 AI 模型的特点，教你如何根据自己的需求选择合适的模型。

需要提醒的是，AI 模型更新很快，这篇文章的内容是基于 2026 年 11 月下旬的情况。未来可能会有新的模型出现，或者现有模型的能力发生变化。所以要保持关注最新动态，灵活调整自己的选择。每次有重要的新模型发布，我都会在本教程模型动态板块中记录实测结果，可以配合着看。



## 一、什么是 AI 模型？

我们先来搞清楚一个基本概念：什么是 AI 模型？

简单来说，**AI 模型就是 Vibe Coding 工具背后的 “大脑”**。

当你在 AI 编程工具中输入需求时，是 AI 模型在理解你说的话；当你看到生成的代码时，也是 AI 模型写出来的。不同的 AI 模型就像不同领域的专家，各有所长。有的擅长写代码、有的擅长整理文献，有的速度快、有的质量高。

打个比方来说：

- AI 编程工具（Cursor、Bolt.new）= 工作台
- AI 模型（Claude、ChatGPT）= 坐在工作台前干活的程序员

所以，同样是用 Cursor，选择 Claude 和选择 ChatGPT，就像请了 2 个不同风格的程序员来帮你写代码，最终的效果自然会不一样。

## 二、主流 AI 模型

截止到 2026 年 11 月，市面上的 AI 模型已经非常丰富了。按照来源和定位，可以分为 3 大阵营：

- 国际顶尖模型：Claude、ChatGPT、Gemini 这三大巨头，以及主打性价比的 Grok
- 国产优秀模型：DeepSeek、智谱 GLM、通义千问、Kimi 等性价比之选
- 还有开源模型：Llama、Qwen 等，需要一定技术能力自己部署

对于我们学习 Vibe Coding 来说，主要关注前两类就够了。开源模型虽然灵活，但配置和使用门槛较高，不太适合新手。

![](https://pic.yupi.icu/1/image-20260106202328517.png)

接下来，我会逐一介绍这些主流模型的特点，帮你找到最适合自己的那一个。



## 三、Claude 最强编码能力

Claude 是 Anthropic 公司推出的 AI 模型系列，一直被公认为编程能力最强的 AI 模型。经过 2026 年的多轮快速迭代，Anthropic 已经完成了 **Claude 5.5 家族**（Opus 5.5、Sonnet 5.5、Haiku 5.5）的全面铺开，并在 2026 年 11 月 9 日发布了最新的顶级旗舰 **Claude Fable 5.2**（同步推出的 Mythos 5.2 去掉了安全护栏，仅面向审核通过的安全和生物机构开放）。

截止到 2026 年 11 月下旬，Claude 的主力在售阵容如下：

| 模型 | 定位 | 价格（输入 / 输出，每百万 token） | 上下文 |
| --- | --- | --- | --- |
| Claude Fable 5.2 | 顶级旗舰，高难推理、长周期 Agent 和极致前端审美 | $8 / $40 | 1M |
| Claude Opus 5.5 | 日常主力旗舰，复杂编程和知识工作性价比最高 | $4 / $20 | 1M |
| Claude Sonnet 5.5 | 速度和智能的最佳平衡，适合中等难度开发 | $2 / $10 | 1M |
| Claude Haiku 5.5 | 极速轻量模型，适合高并发和简单后台任务 | $0.10 / $0.50 起 | 1M |

这代阵容的选型思路很清晰：**日常复杂开发首选 Opus 5.5，常规功能和提速用 Sonnet 5.5，真正要做高难研究、极致视觉呈现或大结果产品时再上 Fable 5.2**。

要注意两点成本细节。第一，虽然 Fable 5.2 单价比上一代 Fable 5.1 降了 20%（缓存读取低至 $0.20 / 百万 token），但实测下来因为模型思考更深、工具调用轮次多，我跑 3 个纯前端高难度项目依然花掉了 500 多块，普通日常任务没必要硬上。第二，Opus 5.5 开到最高推理档位时输出 token 也会明显增多，建议默认保持 medium 档位，遇到真正卡壳的难题再调高推理强度。



### 为什么说 Claude 编程最强？

Claude 在代码理解、架构重构、前端审美和长程调试上的表现都非常突出。全系标配了 1M 上下文窗口、128K 输出上限、自适应思考、上下文压缩和努力度控制，非常适合在 Cursor 或 Claude Code 里做多步骤 Agent 编程。

到了 Fable 5.2，视觉图表理解（Chartography）和真实开源项目合并评测（FrontierCode 2.0）又迈了一大步。我用 3 个纯前端高难度项目实测了 Fable 5.2，上古卷轴、重庆 8D 魔幻城市和纯代码 3D 溶洞的审美依然稳居顶级，但相比 Opus 5.5 的日常体感提升并没有价差那么夸张（详细测评可以阅读本教程模型动态板块中的《Claude Fable 5.2 前端能力实测 - 3 个项目案例》和《Claude Opus 5.5 双模型横评 - 对比 GPT-6 Sol 实测 5 个案例》）。

这些优势让 Claude 特别适合对代码质量和界面审美要求高、做复杂项目的开发者。

**当然，前提是你的预算充足，并且注意官方风控和封号问题**（应对方法可以阅读本板块「Claude Code」目录中的《Claude Code 封号机制和应对方案》）。

![](https://pic.yupi.icu/1/image-20260106221446611.png)

除了编程模型，OpenAI 在 2026 年 11 月还发布了 **ChatGPT Images 2.6**，在 2.5 的手绘草图生图、局部标注修改基础上，进一步支持 **直接生成 GIF 动图、草图转动画、逐帧改台词和参考照片角色复用**，做产品封面、梗图和宣传素材非常方便（可以阅读本教程模型动态板块中的《GPT Images 2.6 动图能力实测 - 7 个创意玩法》和《GPT Images 2.5 生图能力实测 - 10 个创意玩法》）。

## 六、Grok 同价位高性价比选手

除了上面三巨头，xAI（SpaceXAI）的 Grok 系列也值得了解一下。目前主力模型仍为 **Grok 4.7**，定位非常清晰 —— **不追求单项最强，追求同价位里够强**，API 定价每百万 token 输入 2 美元、输出 6 美元（另有速度翻倍的 Fast 版），在 Cursor 和 GitHub Copilot 中都可以直接切换使用。不过要注意 4.7 思考更深入，实际单任务 token 消耗比前代更高，账单不能只看单价。



## 七、国产大模型 - 性价比之选

### 主流国产模型有哪些？

说完了国际模型，我们再来看看国产大模型。如今国产第一梯队在编程、多模态和 1M 长上下文上已经全面追平甚至在部分场景反超国际竞品，价格却往往只有国际旗舰的几分之一：

- **DeepSeek**：开源性价比标杆，主力模型为 **DeepSeek V4.1 Flash（1017 更新版）**，552B 参数 MoE 架构，**原生支持多模态视觉理解** 与 1M 上下文，输出速度极快。日常调 API 模型名统一填 `deepseek-flash`，采用峰谷计费：空闲时段输入缓存命中仅 0.02 元 / 百万 token、未命中 1 元、输出 4 元，工作日高峰时段（9:00 ~ 12:00 和 14:00 ~ 18:00）翻倍，批量任务挪到夜间跑直接省一半（详细实测可以阅读本教程模型动态板块中的《DeepSeek V4.1 Flash 1017 编程能力实测 - 4 个项目案例》）。更重磅的是，2026 年 11 月 DeepSeek 开放了 **全家桶应用 API**，把联网搜索、网页抓取、文件解析、OCR、语音识别/合成和安全审核全部内置到官方 API 里，搜索速度比 Firecrawl 快 10 倍且只要 5 元一千次，开发 AI 应用的门槛大降（详细上手教程可以阅读本板块「工具实战」目录中的《DeepSeek 全家桶 API 实测教程》）。此外它原生支持 OpenAI 与 Anthropic 双协议，可以直接接入 Claude Code 和 Codex（参考「Claude Code」目录中的《Claude Code 和 Codex 对接国内模型教程》）。
- **智谱 GLM**：清华团队出品，全球开源编程模型第一梯队。2026 年 11 月 23 日发布了最新旗舰 **GLM-5.4**（约 750B 参数），首次采用 **Loop Transformer 循环架构**（中间 28 层循环计算两遍）并新增视觉理解，主打「泛 Coding」，在第三方开源编程榜排第一；目前优先通过 GLM Coding Plan 和 ZCode 使用。我用 6 个项目实测下来，只要需求写得够细，GLM-5.4 做官网、Web 应用和 3D 交互页非常稳，但缺点是「雷霆大思考」速度较慢、刚发布高峰期容易限流（详见模型动态板块中的《GLM-5.4 编程能力实测 - 6 个项目案例》）。日常追求速度和低价，则可以选 MIT 开源的原生多模态小钢炮 **GLM-5.3-Flash**（320B / 激活 18B，详见《GLM-5.3-Flash 编程能力实测 - 3 个项目案例》）。
- **阿里通义千问**：2026 年 11 月 16 日正式发布最新旗舰 **Qwen4-Max**（2.4 万亿总参数 MoE，单次激活 71B ~ 95B），原生全模态支持文本、图像和视频输入，拥有 **1M 上下文且无长上下文阶梯加价**，通过阿里云百炼 API 调用定价约输入 $1.5 / 输出 $4.5 每百万 token（或使用 Token Plan 订阅），性价比和长文档处理能力非常突出。
- **月之暗面 Kimi**：2026 年 11 月 4 日开源了最新旗舰 **Kimi K3.1 Pro**（2.8 万亿总参数 MoE，激活 104B），支持 1M 上下文与视觉理解，API 价格约输入 $2 / 输出 $10 每百万 token，实测在前端页面、邮箱类 Web 应用和细节还原上表现非常扎实，同样稳居国产第一梯队。
- **小米 MiMo**：**MiMo-V2.6 系列**（含万亿参数旗舰 `MiMo-V2.6-Pro`、轻量 `V2.6-Flash` 以及极速版 `V2.6-Pro-UltraSpeed`），支持 1M 上下文且价格极低（输入约 $0.44 / 输出约 $0.87 每百万 token），可通过 CC Switch 等工具快捷接入。
- **腾讯混元 CodeBuddy / 百度文心**：分别与腾讯云 3000+ API（等保三级）和百度秒哒等自家生态深度集成，适合企业上云或创意小项目快速落地。



### 国产模型的优势和局限

国产模型最大的优势就是价格便宜、中文理解准确、国内直连稳定且符合合规要求。而且 **1M 长上下文 + 原生多模态视觉** 已经成为国产第一梯队的标配 —— 模型写完页面能自己看截图验收，长程开发的成功率比早期的纯文本模型高了一大截。

当然也有一些局限：在最复杂、需要 AI 自由发挥审美和 3D 精细建模的极端任务上，顶尖上限仍略逊于 Claude Opus 5.5 / Fable 5.2；新旗舰刚发布时也容易出现算力吃紧、高峰限流的问题。但对学生、个人开发者以及绝大多数常规全栈/中文项目来说，国产模型已经完全够打，像我自己的多个线上产品后端都直接接入了 DeepSeek、通义千问或 GLM。

而且我相信，国产模型和开源生态还会越来越强！

## 八、如何选择合适的模型？

这么多模型，各有各的优势，我到底该选哪个呢？其实选择模型主要看两个维度：你的预算和你的使用场景。



### 按预算选择
